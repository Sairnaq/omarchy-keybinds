# Omarchy Keybindings Manager

An interactive graphical keyboard shortcut manager and visual editor for **Omarchy** and **Hyprland**.

---

## 🌟 Features

* **🔍 Real-Time Search**: Search by key combinations (`SUPER + A`, `ALT + ENTER`), descriptions, or commands.
* **🏷️ Category Filtering**: Filter across **Launchers**, **Navigation** (scrolling & workspaces), **Windows** (close, full width, pop out), and **Utilities**.
* **✏️ In-Place Visual Editor**: Edit existing shortcuts or bind new custom keys.
* **💾 Automatic Backup & Live Reload**: Changes are safely appended to `~/.config/hypr/bindings.lua` with automatic timestamped backups, and immediately reloads Hyprland live.
* **⌨️ Keyboard First**: Press `Esc` to exit, use arrow keys to navigate, or click with mouse.

---

## 🚀 Installation & Usage

### 1. Installation
```bash
git clone https://github.com/Sairnaq/omarchy-keybinds.git ~/.config/omarchy/plugins/omarchy-keybinds
chmod +x ~/.config/omarchy/plugins/omarchy-keybinds/keybind-manager
```

### 2. How to Launch
* **Shortcut**: **`Super + Shift + K`**
* **From Terminal**: `omarchy-keybinds`
* **From Omarchy Menu**: Search `Keybindings Manager` in the app launcher.
